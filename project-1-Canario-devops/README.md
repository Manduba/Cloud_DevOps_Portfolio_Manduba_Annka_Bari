# Canario DevOps Prototype

This project contains files from an academic DevOps prototype for the Canario case study.

The project demonstrates selected DevOps concepts, including:

- FastAPI web application prototype
- Docker containerization
- GitLab CI/CD build and test stages
- Environment-variable-based feature control using GET_LEVEL

## Tools Used

- Python
- FastAPI
- Docker
- GitLab CI/CD

## Project Status

This is an academic prototype, not a production-ready application.

## Notes

The GitLab CI/CD configuration is included as `gitlab-ci.yml` to show the pipeline prototype used in the report.
