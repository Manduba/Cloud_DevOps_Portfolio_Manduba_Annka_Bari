# Project Summary

This project was created as part of an academic DevOps case study for Canario.

The goal was to explore how a company with manual deployment, limited testing, and weak release control could move toward a DevOps workflow.

The prototype includes:

- A FastAPI web application
- Docker-based containerization
- GitLab CI/CD build and test stages
- Environment-variable-based feature control using `GET_LEVEL`

The project is not a full production system. It is a practical academic prototype showing selected DevOps concepts.
